Уведомление о файлах cookie

Коротко о файлах cookie: что использует этот сайт, а что нет.

Это перевод для вашего удобства. Если русская и английская версии расходятся, действует английская версия.

1. Что такое файлы cookie

Файлы cookie представляют собой небольшие файлы, которые сайт сохраняет на вашем устройстве. Некоторые из них нужны, чтобы сайт работал. Другие отслеживают, как используется сайт, или помогают с рекламой.

2. Что использует этот сайт

  • Необходимые файлы cookie. Сам сайт не сохраняет файлы cookie. Если вы переключаете цены между фунтами и евро, ваш браузер запоминает этот выбор на вашем устройстве, чтобы не спрашивать снова. Эта информация никуда не передаётся: ни мне, ни кому-либо ещё.
  • Аналитические файлы cookie. Их нет. Чтобы видеть, сколько людей заходит на сайт и какие страницы они читают, и делать сайт удобнее, я использую Cloudflare Web Analytics. Этот сервис не ставит cookie, не узнаёт, кто вы, и не следит за вами на других сайтах. Cloudflare только считает посещения для меня, показывает мне общие цифры (например, просмотренные страницы, с какого сайта вы пришли, тип устройства и страну) и больше ни для чего эти данные не использует. Если не хотите попадать в подсчёт, нажмите кнопку ниже. Ваш выбор сохранится на этом устройстве.
  • Рекламные файлы cookie. Сейчас не используются. Если я когда-нибудь начну их использовать, это будет указано на этой странице, и сначала у вас спросят согласие.

3. Ваш выбор

Сайт не использует файлы cookie, для которых нужно ваше согласие, поэтому баннера с выбором здесь нет.

Всё, что браузер сохранил для этого сайта, можно в любой момент удалить в его настройках.

4. Встроенный контент

На некоторых страницах работают сервисы других компаний: календарь записи Cal.com на странице «Контакты», MailerLite для формы получения бесплатного дневника и Google Fonts для шрифтов. Cal.com может сохранять собственные файлы cookie, чтобы календарь записи работал, а у каждого сервиса есть своё уведомление о конфиденциальности.
